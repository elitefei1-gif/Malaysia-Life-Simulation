Mini Game for life simulation (Malaysia)

## For development

Plain HTML, CSS and JavaScript with no build step. GitHub Pages serves this folder as it is.

- `index.html` is the page. `css/style.css` holds the styling and `js/` holds the game code (see `CLAUDE.md` for what each file does).
- `npm install` then `npm test` plays random lives in a headless browser and checks for errors.
- `npm run serve` starts the game at http://localhost:8080.
- `node tools/bump-version.mjs` sets the version before each release.
